# ROS2 tutorials

Listener/Talker: Simple publication of std_msgs String topic between two nodes in C++ (Listener and Talker).

Code tested under Ubuntu 24.04 + ROS2 jazzy distro

Code is based on [ros2 official examples](https://github.com/ros2/examples) but it's made simpler (or so I tried).

They are well structured so they can be used as templates.

Multiple ROS2 pkg combinations are demonstrated:

- only python
- only c++ pkg
- hybrid: pkg with c++ and python code
- no code (meanto be used for storing launch and config files).
